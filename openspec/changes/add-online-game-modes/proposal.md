# Change: Add Online Game Modes and Kick

## Why
联机对战目前只有一种固定的玩法（10 个单词的 Word Drop），房主也无法管理房间里的玩家。需要：
- 房主可以把玩家踢出房间
- 提供更多玩法，并让房主调整单局的个数和时长
- 新增一种“抢地盘”式的单词池玩法，可以选择是否允许掠夺别人的单词

## What Changes
- **踢人**：房主在大厅按 K 打开选人框，用上下键选中玩家后按回车踢出。被踢的玩家回到联机菜单并看到 “You were kicked”，之后仍可从列表重新加入
- **大厅设置与滚轮页面**：大厅竖排列出玩法、各项设置和 Start Game，房主用上下键选择、回车进入。进入调整后，其他选项和玩家列表全部隐藏，左边只留这一项的名称，右边出现滚轮：当前值高亮并与名称同一行，上下各显示两个相邻档位并逐级变淡，上下键滚动、回车确认、Esc 取消。全部是预设档位，不需要打字输入；确认后所有人都能看到新设置。设置项随玩法变化：
  - Word Drop：单词个数、整局时间上限
  - Sentence Race：句子个数、整局时间上限
  - Word Pool：游戏时长、每秒出词个数、是否允许掠夺
- **Word Drop 支持配置**：单词个数和整局时间上限可调，二者先到者结束；单词掉落速度仍取 `online_drop_duration`
- **新玩法 Sentence Race（整句）**：
  - 一次显示一整句，谁先完整打对并回车就得到这一句，分数等于句中的字母数（不算空格和标点）
  - 输入时逐字标出对错；回车时有错不会清空，可以退格修改
  - 一句被拿走后显示结果，1 秒后换下一句；句子个数和整局时间上限先到者结束
- **新玩法 Word Pool（单词池）**：
  - 盘面固定 36 格，按设定的速度每秒出新单词
  - 谁先打对某个空闲单词并回车，这个单词就变成他的颜色
  - 允许掠夺时，也可以输入别人已占有的单词把它抢过来；自己的单词不能重复抢
  - 盘面满了以后，新单词替换最早出现、还没人占有的单词；全部被占满后不再出新词
  - 时间到时，每人按手中单词的字母数计分，分高者胜
- **协议**：协议版本升到 3。新增 `kick`、`kicked`、`set_option` 消息，`lobby`、`game_start` 携带设置；新增整句和单词池相关的消息

## Impact
- **依赖**：基于 `add-lan-room-discovery` 归档后的规范编写，需要先归档该变更，再归档本变更
- **受影响规范**：
  - `online-room` - 修改房间大厅需求（踢人、设置面板、多种玩法）
  - `online-word-drop` - 修改开局、结束和结算需求（个数和时间上限可配置）
  - `ui-rendering` - 修改联机界面渲染（大厅设置面板、踢人、新玩法界面）
  - `online-sentence-race`（新增）- 整句玩法
  - `online-word-pool`（新增）- 单词池玩法
- **受影响代码**：
  - `pkg/online/protocol.go` - 新消息、设置结构体、版本号
  - `pkg/online/settings.go`（新增）- 各玩法的设置项、取值范围和默认值
  - `pkg/online/server.go` - 踢人、设置、按玩法分派
  - `pkg/online/mode_*.go`（新增）- 三种玩法的服务端规则
  - `pkg/online/battle.go` - 客户端状态支持三种玩法
  - `pkg/game/game.go` - 新增 `DrawSentences`
  - `pkg/ui/online.go` - 大厅设置面板、两种新玩法的界面
  - `cmd/word-killer/online.go` - 大厅选择与踢人按键、各玩法的输入处理
- **兼容性**：协议版本升到 3，旧版本客户端看不到新版房间，也无法加入
