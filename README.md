# Word Killer - 打字游戏

> 低调但绝不简单的命令行打字游戏

## 介绍

Word Killer 是一个基于命令行的打字游戏，通过消除屏幕上的单词来提升你的打字速度和准确度。

## 功能特性

- ✨ **多种游戏模式**:
  - 🎯 **经典模式**: 消除固定数量的单词
  - 📝 **句子模式**: 完整输入句子
  - ⏱️ **倒计时模式**: 60秒限时挑战
  - 🏃 **极速模式**: 25词速度竞赛，追踪最佳记录
  - 🎵 **节奏大师**: 逐词限时，难度递增
- 🎯 **实时匹配**: 输入时即时高亮匹配的单词
- ⏸️ **暂停功能**: 支持游戏暂停和恢复
- 📊 **详细统计**: 完整的数据统计（速度、准确率等）
- 🎨 **彩色界面**: 使用 ANSI 颜色的精美命令行界面
- ⚙️ **可配置**: 支持自定义词库和游戏设置

## 快速开始

### 编译

```bash
make build        # 输出到 build/（包含 word-killer.exe、start.bat、config.json、data/）
# 或直接使用 go build
go build -o word-killer.exe ./cmd/word-killer
```

### 运行

```bash
make run          # 编译并在 build/ 目录内运行
# 或
./word-killer.exe
```

Windows 上推荐双击 `build/start.bat` 启动，它会把窗口调整到合适的大小：
- 装了 Windows Terminal 时，用 `wt --size` 打开一个 90 × 34 的新窗口
- 否则在当前控制台窗口执行 `mode con` 调整大小后运行

游戏至少需要 **82 列 × 32 行** 的窗口。窗口太小时不会显示游戏画面，而是提示需要的大小和当前大小，把窗口拉大后自动恢复。

执行 `make help` 可以查看全部目标（test、clean、build-all 等）。

## 游戏玩法

### 开始游戏

1. 运行游戏后，进入欢迎界面
2. 选择 **开始游戏**，进入模式选择
3. 使用 `↑` `↓` 键选择游戏模式：
   - **经典模式**: 消除固定数量单词（默认50个）
   - **句子模式**: 完整输入英文句子
   - **倒计时模式**: 60秒限时，消除尽可能多的单词
   - **极速模式**: 固定25个单词，追求最快完成时间
   - **节奏大师**: 每个单词限时完成，难度逐步递增
4. 按 `Enter` 开始游戏

### 游戏操作

1. **输入匹配**: 输入字母匹配屏幕上的单词（自动高亮）
2. **消除单词**: 完整输入单词后按 `Enter` 消除
3. **暂停**: 按 `ESC` 进入暂停菜单
4. **退出**: 在暂停菜单或结果页选择相应选项

### 按键说明

| 按键 | 功能 |
|------|------|
| `a-z` | 输入字母 |
| `Enter` | 消除匹配的单词 |
| `Backspace` | 删除最后一个字符 |
| `ESC` | 暂停游戏 / 返回上级菜单 |
| `↑` / `↓` / `k` / `j` | 菜单中导航 |

### 游戏模式详解

#### 🎯 经典模式
- 消除固定数量的单词（默认50个）
- 无时间限制，专注于准确性
- 适合练习打字基础

#### 📝 句子模式
- 完整输入英文句子
- 支持空格和标点符号
- 适合练习真实文本输入

#### ⏱️ 倒计时模式
- 60秒限时挑战
- 消除尽可能多的单词
- 剩余单词少于10个时自动补充
- 时间少于10秒时红色警告

#### 🏃 极速模式
- 固定25个单词
- 毫秒级精度计时
- 自动保存最佳记录
- 追求速度极限

#### 🎵 节奏大师
- 每个单词有时间限制（初始2秒）
- 每完成10个单词，时间限制减少0.1秒
- 最小时间限制0.5秒
- 任何单词超时即游戏结束
- 挑战反应速度和节奏感

## 联机对战

在欢迎界面选择 **Online**，即可和同一局域网中的朋友对战（每个房间 2–4 人）。

### 创建房间
1. 选择 **Create Room**，进入大厅后，同一局域网的玩家会自动看到这个房间
2. 在大厅里选择玩法、调整参数（见下方“大厅操作”）
3. 人数达到 2 人后，选中 **Start Game** 按 `Enter` 开始对局

### 加入房间
1. 进入 **Online** 后，局域网里的房间会自动出现在 **Rooms on your network** 列表中，每秒刷新
2. 用 `↑↓` 选中一个显示 **Waiting** 的房间，按 `Enter` 直接加入
3. 显示 **Full**（已满）或 **In game**（对局中）的房间是灰色的，暂时不能加入

### 大厅操作
- **房主**：
  - `↑↓` 在玩法、各项参数和 **Start Game** 之间选择，`Enter` 进入
  - 进入参数后，其他选项隐藏，右侧出现滚轮：`↑↓` 滚动，`Enter` 确认，`Esc` 取消
  - 按 `K` 打开踢人列表，`↑↓` 选择玩家，`Enter` 踢出，`Esc` 取消。被踢的玩家可以重新加入
- **所有玩家**：按 `Tab` 修改自己的昵称（`Enter` 保存，`Esc` 取消）
- 每名玩家有固定的颜色（红、蓝、绿、黄），比分栏、盘面和结算界面都用这个颜色

### 玩法
所有玩法中，“个数”和“时间上限”先到者结束，结束后总分最高者获胜，同分并列。

| 玩法 | 可调参数（默认值） |
|------|------------------|
| Word Drop | 单词个数 5–30（10），时间上限 60–300 秒（120） |
| Sentence Race | 句子个数 3–10（5），时间上限 60–300 秒（180） |
| Word Pool | 游戏时长 30–120 秒（60），每秒出词 1–3 个（1），是否允许掠夺（关） |

**Word Drop（单词掉落）**
- 一次掉落一个单词，谁先完整无误地输入并按 `Enter`，谁就拿到这个单词，得分 = 单词字母数
- 按 `Enter` 时输错只会清空输入，不扣分；单词掉到底还没人拿到就作废

**Sentence Race（整句竞速）**
- 一次显示一整句，谁先完整打对并按 `Enter`，谁就得到这一句，得分 = 句中字母数（不算空格和标点）
- 输入时正确的部分为绿色、错误的部分为红色；按 `Enter` 时有错不会清空，可以退格修改

**Word Pool（单词池）**
- 6×6 的盘面上按设定的速度不断出现新单词，打对一个空闲单词并按 `Enter`，它就变成你的颜色
- 开启掠夺后，也可以输入别人已占有的单词把它抢过来（自己的单词不能重复抢）
- 盘面满了，新单词会替换最早出现、还没人占有的单词
- 时间到时，每人按手中单词的字母数计分

### 注意事项
- 只支持同一局域网（同一网段）联机。跨网段、VPN，或者开启了客户端隔离的公司 / 访客 Wi-Fi，房间都不会出现在列表中
- 房主需要在防火墙中放行 `online_port`（默认 7788）的 **TCP 和 UDP**；首次使用时 Windows 可能会弹窗询问，请选择允许
- 所有玩家的 `online_port` 必须一致，并且使用同一版本的游戏；版本不同的房间不会出现在列表中
- 联机没有身份验证，请只在可信的网络中使用

## 配置文件

配置文件位置：`config.json`

### 快速配置示例

```json
{
  "word_count": 50,
  "short_ratio": 30,
  "medium_ratio": 50,
  "long_ratio": 20,
  "countdown_duration": 60,
  "speedrun_word_count": 25,
  "rhythm_initial_time_limit": 2.0,
  "rhythm_min_time_limit": 0.5,
  "rhythm_difficulty_step": 0.1,
  "rhythm_words_per_level": 10
}
```

### 主要配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `word_count` | 经典模式单词数量 | 50 |
| `short_ratio` | 短单词比例权重 | 30 |
| `medium_ratio` | 中等单词比例权重 | 50 |
| `long_ratio` | 长单词比例权重 | 20 |
| `countdown_duration` | 倒计时模式时长（秒） | 60 |
| `speedrun_word_count` | 极速模式单词数 | 25 |
| `rhythm_initial_time_limit` | 节奏大师初始时限（秒） | 2.0 |
| `rhythm_min_time_limit` | 节奏大师最小时限（秒） | 0.5 |
| `rhythm_difficulty_step` | 节奏大师每级减少时间（秒） | 0.1 |
| `rhythm_words_per_level` | 节奏大师每级所需单词数 | 10 |
| `online_port` | 联机房间端口 | 7788 |
| `online_drop_duration` | 联机单词掉落时长（秒） | 8 |
| `online_player_name` | 联机昵称（留空为系统用户名） | 系统用户名 |

> 📖 **详细配置说明**: 请查看 [CONFIG.md](CONFIG.md) 获取完整的配置文档和示例

### 难度预设

**简单模式** (适合新手):
```json
{
  "short_ratio": 50, "medium_ratio": 40, "long_ratio": 10,
  "countdown_duration": 90,
  "speedrun_word_count": 15,
  "rhythm_initial_time_limit": 3.0,
  "rhythm_min_time_limit": 1.0
}
```

**困难模式** (适合高手):
```json
{
  "short_ratio": 10, "medium_ratio": 40, "long_ratio": 50,
  "countdown_duration": 30,
  "speedrun_word_count": 40,
  "rhythm_initial_time_limit": 1.5,
  "rhythm_min_time_limit": 0.3
}
```

## 词库文件

项目包含三个难度级别的词库：

- `data/google-10000-short.txt`: 短单词（3-5个字母）
- `data/google-10000-medium.txt`: 中等单词（6-8个字母）
- `data/google-10000-long.txt`: 长单词（9+个字母）
- `data/sentences.txt`: 句子库（用于句子模式）

词库文件格式为文本文件，每行一个单词/句子，仅包含字母（a-z）。

## 统计指标

游戏结束后会显示以下统计数据：

- **总敲击数**: 所有按键次数
- **有效敲击数**: 匹配到单词的按键次数
- **正确字符数**: 正确输入的字符数
- **完成单词数**: 成功消除的单词数
- **总字母数**: 所有已消除单词的总字母数
- **总耗时**: 游戏时长（排除暂停时间）
- **字母速度**: 字母数/秒
- **单词速度**: 单词数/秒
- **准确率**: 正确字符数 / 总敲击数 × 100%
